# Histórico — enfoque previo a la redefinición (17 de agosto – 2 de septiembre de 2026)

Material de la primera fase del trabajo, cuando el eje era un protocolo de eventos basado en
Contact ID (SIA DC-05) sobre DC-09. El 2 de septiembre el enfoque se redefinió hacia el monitoreo
continuo de sensores por TCP/IP (ver `bitacora/2026-09-02-reunion-pivote.md` y el anexo D del
informe oficial). Se conserva como evidencia de la evaluación realizada y de por qué se cambió; no
describe el sistema actual.

| Carpeta | Contenido |
|---|---|
| `docs/05-protocolo-contactid.md` | Evaluación del protocolo Contact ID y alternativas |
| `herramientas/contactid.py` | Generador y validador de mensajes Contact ID (Python) |
| `informe-v1/` | Primera versión extendida del informe (LaTeX), anterior a la plantilla oficial |
| `docs/referencias-contactid.bib` | Nueve referencias del protocolo descartado (SIA DC-05/DC-09/DC-03, CoAP, LwM2M, Verisure, Ademco), sin citar en el informe vigente; movidas aquí el 23/09/2026 |
